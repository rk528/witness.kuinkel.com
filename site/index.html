File Download With certutil T1105 high Awaiting lab capture

Detects certutil.exe fetching a remote URL with -urlcache or -verifyctl. certutil is signed by Microsoft and present on every Windows host, so it is a favourite way to pull a second stage past application allow-listing. Requiring a URL scheme keeps routine cache maintenance such as "certutil -urlcache * delete" quiet.

Sigma rule · Evidence

Recorded attack it must catch

Not recorded yet. The rule only counts as proven once scripts/capture.ps1 has recorded the real attack in the lab and the rule fires on every recorded test.

Normal activity it must ignore

ResultScenarioCommand line
QuietChecking a download's SHA-256 hashcertutil.exe -hashfile C:\Users\analyst\Downloads\setup.exe SHA256
QuietClearing the URL cache (cache flag, but no URL)certutil.exe -urlcache * delete
QuietVerifying a certificate filecertutil.exe -verify C:\certs\root.cer

Ready-to-run queries

Microsoft Sentinel (ASIM, KQL)
imProcessCreate
| where (TargetProcessName endswith "\\certutil.exe" or TargetProcessFileOriginalName =~ "CertUtil.exe") and (TargetProcessCommandLine contains "-urlcache" or TargetProcessCommandLine contains "/urlcache" or TargetProcessCommandLine contains "–urlcache" or TargetProcessCommandLine contains "—urlcache" or TargetProcessCommandLine contains "―urlcache" or TargetProcessCommandLine contains "-verifyctl" or TargetProcessCommandLine contains "/verifyctl" or TargetProcessCommandLine contains "–verifyctl" or TargetProcessCommandLine contains "—verifyctl" or TargetProcessCommandLine contains "―verifyctl") and (TargetProcessCommandLine contains "http://" or TargetProcessCommandLine contains "https://" or TargetProcessCommandLine contains "ftp://")
Microsoft Defender XDR (KQL)
DeviceProcessEvents
| where (FolderPath endswith "\\certutil.exe" or ProcessVersionInfoOriginalFileName =~ "CertUtil.exe") and (ProcessCommandLine contains "-urlcache" or ProcessCommandLine contains "/urlcache" or ProcessCommandLine contains "–urlcache" or ProcessCommandLine contains "—urlcache" or ProcessCommandLine contains "―urlcache" or ProcessCommandLine contains "-verifyctl" or ProcessCommandLine contains "/verifyctl" or ProcessCommandLine contains "–verifyctl" or ProcessCommandLine contains "—verifyctl" or ProcessCommandLine contains "―verifyctl") and (ProcessCommandLine contains "http://" or ProcessCommandLine contains "https://" or ProcessCommandLine contains "ftp://")
Splunk (Sysmon, SPL)
source="WinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1 Image="*\\certutil.exe" OR OriginalFileName="CertUtil.exe" CommandLine="*-urlcache*" OR CommandLine="*/urlcache*" OR CommandLine="*–urlcache*" OR CommandLine="*—urlcache*" OR CommandLine="*―urlcache*" OR CommandLine="*-verifyctl*" OR CommandLine="*/verifyctl*" OR CommandLine="*–verifyctl*" OR CommandLine="*—verifyctl*" OR CommandLine="*―verifyctl*" CommandLine IN ("*http://*", "*https://*", "*ftp://*")
LSASS Memory Dump via comsvcs.dll MiniDump T1003.001 high Awaiting lab capture

Detects rundll32 calling the MiniDump export of comsvcs.dll, a built-in way to dump LSASS memory without bringing any tools. Attackers often call the export by its ordinal (#24) to dodge string matches, so both forms are covered. The OriginalFileName branch still fires when rundll32.exe has been copied and renamed.

Sigma rule · Evidence

Recorded attack it must catch

Not recorded yet. The rule only counts as proven once scripts/capture.ps1 has recorded the real attack in the lab and the rule fires on every recorded test.

Normal activity it must ignore

QuietOpening the printer install wizardrundll32.exe printui.dll,PrintUIEntry /il
QuietClearing Internet Explorer browsing datarundll32.exe inetcpl.cpl,ClearMyTracksByProcess 8

Ready-to-run queries

Microsoft Sentinel (ASIM, KQL)
imProcessCreate
| where (TargetProcessName endswith "\\rundll32.exe" or TargetProcessFileOriginalName =~ "RUNDLL32.EXE") and TargetProcessCommandLine contains "comsvcs" and (TargetProcessCommandLine contains "minidump" or TargetProcessCommandLine contains "#24" or TargetProcessCommandLine contains "#+24")
Microsoft Defender XDR (KQL)
DeviceProcessEvents
| where (FolderPath endswith "\\rundll32.exe" or ProcessVersionInfoOriginalFileName =~ "RUNDLL32.EXE") and ProcessCommandLine contains "comsvcs" and (ProcessCommandLine contains "minidump" or ProcessCommandLine contains "#24" or ProcessCommandLine contains "#+24")
Splunk (Sysmon, SPL)
source="WinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1 Image="*\\rundll32.exe" OR OriginalFileName="RUNDLL32.EXE" CommandLine="*comsvcs*" CommandLine IN ("*minidump*", "*#24*", "*#+24*")
PowerShell Launched With an Encoded Command T1059.001 T1027 medium Awaiting lab capture

Detects powershell.exe or pwsh.exe started with -EncodedCommand or one of its short forms. Encoding hides the real script from command-line logging, which is why loaders and C2 stagers use it. The flag list deliberately leaves out "-enco": it also matches "-Encoding" inside ordinary -Command scripts and was the main source of noise.

Scheduled Task Created to Run From a User-Writable Folder T1053.005 medium Awaiting lab capture

Detects schtasks /create where the task runs something out of Temp, Public or the roaming profile. Malware drops its payload where any user can write and then adds a task for persistence. AppData\Local as a whole is left out on purpose: OneDrive, Teams and other per-user updaters legitimately schedule tasks from there.

Shadow Copies or Backup Catalog Deleted T1490 high Awaiting lab capture

Detects the commands ransomware runs just before encrypting, to stop the victim rolling back: deleting Volume Shadow Copies with vssadmin, wmic or PowerShell, deleting the Windows Backup catalog, and turning off boot recovery with bcdedit. Read-only commands such as "vssadmin list shadows" or "bcdedit /enum" do not match.

Sigma rule · Evidence

Recorded attack it must catch

Not recorded yet. The rule only counts as proven once scripts/capture.ps1 has recorded the real attack in the lab and the rule fires on every recorded test.

Ready-to-run queries

Microsoft Sentinel (ASIM, KQL)
imProcessCreate
| where (TargetProcessName endswith "\\vssadmin.exe" and (TargetProcessCommandLine contains "delete" and TargetProcessCommandLine contains "shadows")) or (TargetProcessName endswith "\\wmic.exe" and (TargetProcessCommandLine contains "shadowcopy" and TargetProcessCommandLine contains "delete")) or ((TargetProcessName endswith "\\powershell.exe" or TargetProcessName endswith "\\pwsh.exe") and (TargetProcessCommandLine contains "Win32_ShadowCopy" and TargetProcessCommandLine contains "Delete")) or (TargetProcessName endswith "\\wbadmin.exe" and (TargetProcessCommandLine contains "delete" and TargetProcessCommandLine contains "catalog")) or (TargetProcessName endswith "\\bcdedit.exe" and (TargetProcessCommandLine contains "recoveryenabled no" or TargetProcessCommandLine contains "bootstatuspolicy ignoreallfailures"))
Microsoft Defender XDR (KQL)
DeviceProcessEvents
| where (FolderPath endswith "\\vssadmin.exe" and (ProcessCommandLine contains "delete" and ProcessCommandLine contains "shadows")) or (FolderPath endswith "\\wmic.exe" and (ProcessCommandLine contains "shadowcopy" and ProcessCommandLine contains "delete")) or ((FolderPath endswith "\\powershell.exe" or FolderPath endswith "\\pwsh.exe") and (ProcessCommandLine contains "Win32_ShadowCopy" and ProcessCommandLine contains "Delete")) or (FolderPath endswith "\\wbadmin.exe" and (ProcessCommandLine contains "delete" and ProcessCommandLine contains "catalog")) or (FolderPath endswith "\\bcdedit.exe" and (ProcessCommandLine contains "recoveryenabled no" or ProcessCommandLine contains "bootstatuspolicy ignoreallfailures"))
Splunk (Sysmon, SPL)
source="WinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1 (Image="*\\vssadmin.exe" CommandLine="*delete*" CommandLine="*shadows*") OR (Image="*\\wmic.exe" CommandLine="*shadowcopy*" CommandLine="*delete*") OR (Image IN ("*\\powershell.exe", "*\\pwsh.exe") CommandLine="*Win32_ShadowCopy*" CommandLine="*Delete*") OR (Image="*\\wbadmin.exe" CommandLine="*delete*" CommandLine="*catalog*") OR (Image="*\\bcdedit.exe" CommandLine IN ("*recoveryenabled no*", "*bootstatuspolicy ignoreallfailures*"))
